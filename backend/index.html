異常通報中心
當個案出現握力不足、坐站偏慢、步速偏慢、SMI 偏低或血壓異常時，會自動出現在這裡，並列出該次完整身體數據。
匯入真實檢測資料

支援 CSV 與 Excel (.xlsx)。系統會自動對應中英文欄位、計算 BMI、判斷肌少症分期，並去重。

建議欄位：身分證、姓名、性別、年齡、身高、體重、體脂率、SMI、收縮壓、舒張壓、脈搏、握力、五次坐站、走路時間、檢測時間

也可直接呼叫 API：

POST /api/import (multipart/form-data, field: file)
RESTful API 說明

本系統提供真實可用的後端 API，可讓醫療 HIS、長照平台、物聯網檢測設備串接。

方法路徑說明
POST/api/auth/login登入取得 JWT
POST/api/measurements新增單筆檢測（JSON）
GET/api/measurements查詢列表（支援篩選分頁）
GET/api/cases/{id_card}個案完整歷史與最新數據
POST/api/import批次匯入 CSV/Excel
GET/api/stats統計與趨勢
GET/api/export/csv匯出 CSV
